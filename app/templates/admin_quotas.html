Client Quotas

Manage subscribed test-case counts and service entitlement per access code.

A client with no row below cannot generate or execute anything — every access code must be created below with an explicit service entitlement before it can be used (fail-closed default as of 2026-09-21). Once a quota exists, generation is blocked once either 5 attempts or 1.5× the subscribed kept-case count is reached, whichever comes first — "Consumed" is permanent once a client keeps a generated set. Service entitlement is a separate, stricter gate controlling whether a code can use generation or execution at all, not just how much. Use Add a new client below to onboard someone — it creates the code, quota, and entitlement together, with no server restart needed.
