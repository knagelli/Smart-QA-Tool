Client Quotas

A client with no quota row here can generate without any restriction (fail-open default for legacy/unconfigured clients). Setting a quota turns on enforcement: generation is blocked once EITHER 5 attempts OR 1.5x the subscribed count of kept test cases is reached, whichever comes first. "Consumed" is permanent once a client keeps/downloads a generated set - it never decreases.
